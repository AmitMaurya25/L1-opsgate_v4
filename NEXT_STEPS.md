## Design decisions / deviations (decision log)
- Router is deterministic regex → typed route (reliable, testable); LLM only synthesizes grounded text. Plan allowed this; revisit if routing misses appear in real data.
- Approval: draft hash over immutable fields, expiry, ownership by session, atomic `BEGIN IMMEDIATE`, idempotent ticket insert, metrics emitted only after commit. State is one JSON blob per owner in SQLite (fine for demo; migrate to tables for production).
- Frontend: original light-theme HTML kept; changes = backend event bridge, reject→backend, NDMC team entry, staff-only trace/arch tab (`window.STAFF`). `frontend/original.html` is untouched for comparison.
- Telemetry merged into the engine (replaces the separate `instrumented_engine.py` adapter from the observability add-on); new metrics: guardrail blocks, retrieval outcomes, tool calls, LLM retries/fallbacks, drafts, error types.
- Python 3.13 per guide (CI updated from 3.11).
